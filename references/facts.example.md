# 事实库（模板）

> **复制这个文件为 `references/facts.md`，填入你自己的事实。** `facts.md` 已被 `.gitignore` 排除。
>
> 规则（`jjstack` 的硬约定）：技能里涉及"你做过什么"的陈述**只能引用这个文件**。文件里没有的不写。
> 这样套件不会替你说没做过的话。

## 真实性分级

| 级别 | 含义 | 用法 |
|---|---|---|
| ✅ 已核实 | 有代码 / 官方接口 / 公开页面直接证据 | 可直接引用 |
| 🟡 本人陈述 | 出自自己的材料，无第三方证据 | 可写，但不得再加码 |
| ⚠️ 需限定表述 | 证据与表述有落差 | 改写口径后才可写 |
| ❌ 不可使用 | 无证据或被反向证据推翻 | 禁止写入 |

## 身份

- 姓名 / 常驻城市 / 公开站点 / GitHub：✅
- 教育经历（学校、专业、起止、预计毕业时间）：✅
  - ⚠️ **毕业时间会决定你能投哪些通道，定稿前必须确认真实学制**
- 语言能力：🟡

> 只放**已公开**的信息。手机号、邮箱、身份证、住址一律不写进本文件。

## 项目（每个项目复制这一段）

### <项目名>

- **一句话**：<不是做什么，而是解决了谁的什么困境>
- **你的角色**：<独立 / 团队几人 / 你负责哪一部分>
- **时间**：<起止>
- **可交付状态**：<上架 / 内测 / 实机 / 开源 / 概念> — 级别 <✅/🟡/⚠️>
- **已核实的数字**：
  - <指标> = <数值>（来源：<代码路径 / 官方接口 / 公开页面>）— 级别
- **边界（必须写一条）**：<这版不能证明什么 / 哪个环节还没闭环>
- **引用他人成果**：<上游是谁 + 你做了什么>（若有）

**口径纪律**：任何数字都要能回答四问——怎么测的、样本多少、对照组是什么、适用边界到哪。

## 技能分级

**A 档（有生产级代码，可写"熟练/独立实现"）**
<例：Swift · SwiftUI · Python · FastAPI>

**B 档（加限定才可写）**
<例：某框架 —— 只在一个小工具里用过 → "做过单场景原型">

**C 档（删除）**
<例：只在教程里跟做过、简历里写过但代码里没有的>

**判定方法**：对每个技能声明，去代码库里找证据。找不到就降级或删除。
